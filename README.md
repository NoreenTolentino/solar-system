# Solar System in Pure CSS

An animated solar system built with only HTML and CSS. No JavaScript or libraries.

**Live preview:** [https://your-username.github.io/solar-system/](https://your-username.github.io/solar-system/)

## Features

- 8 planets with independent orbit speeds, an asteroid belt, Saturn's rings, and Earth's moon
- Hover to pause and see each planet's name and year length
- Responsive, keyboard accessible, and respects `prefers-reduced-motion`

## Run locally

Clone the repo and open `index.html` in a browser.
